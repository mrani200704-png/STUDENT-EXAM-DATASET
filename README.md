Student Performance Prediction Using Logistic Regression
Overview

This project predicts whether a student will Pass or Fail using academic and personal factors such as study hours, attendance, past exam scores, parental education, internet access, and extracurricular activities.

Objectives
Analyze student performance data using EDA.
Identify factors affecting academic success.
Build a Logistic Regression model for Pass/Fail prediction.
Detect high-risk students early.
Visualize insights through dashboards.
Technologies Used
Python
Pandas & NumPy
Matplotlib & Seaborn
Scikit-Learn
Plotly
Streamlit
Features
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Correlation Analysis
Risk Categorization
Logistic Regression Prediction
Interactive Dashboard
Model Evaluation
Accuracy
Precision
Recall
F1-Score
Confusion Matrix
ROC-AUC Score
Outcome

The system helps educational institutions identify at-risk students early, improve academic performance, and support data-driven decision-making.
